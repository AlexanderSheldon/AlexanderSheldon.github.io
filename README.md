# Alexander Sheldon Portfolio

A static GitHub Pages portfolio featuring selected data analytics work, including OpenEarthMap semantic segmentation and coyote home-range analysis.

## Preview locally

Open `index.html` in a browser. The site has no build step or JavaScript dependency. Fonts load from Google Fonts when online; system fallbacks are included. The coyote case study uses a locally bundled conceptual KDE/MCP schematic; its captions link to the published page for the original result maps.

## Project files

The OpenEarthMap case study is at `projects/openearthmap-segmentation/`. Its `source/` folder contains copies of the training and comparison notebooks with saved outputs removed, plus the course report. The coyote KDE/MCP case study is at `projects/coyote-home-range/` and links to its published source page. The original OpenEarthMap notebooks remain in the separate project folder; no coyote collar data or analysis code is included.

## Publish with GitHub Pages

In the repository settings, open **Pages** and deploy from the repository's default branch and root folder. The `index.html` file is the site entry point; no workflow or build command is required.

Dataset and source imagery credits are included in the project case study. The OpenEarthMap source imagery may have region-specific reuse terms.
